# iRede — Frontend Dashboard (Administração)

Painel administrativo do sistema de certificados iRede — gestão de emissões de
certificados de participação, participantes (Residentes e Alunos), desafios e
tokenomics da moeda utilitária **Utility iRede Coin (iRede.c)** na blockchain
**Polygon**.

Este repositório é um **submódulo** do projeto principal
[carlosdelfino/irede_web3_moeda_certificado](https://github.com/carlosdelfino/irede_web3_moeda_certificado).

## Escopo do módulo

- Gestão de participantes, coortes, etapas e desafios.
- Emissão, revogação e auditoria de certificados.
- Parametrização da distribuição de iRede.c por etapa e desafio.
- Relatórios e indicadores de participação e de emissões on-chain.
